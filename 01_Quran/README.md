## Scholarly Provenance & Authority
- **Arabic Text Authority**: King Fahad Complex for the Printing of the Holy Quran (مجمع الملك فهد لطباعة المصحف الشريف - المدينة المنورة).
- **Text Recension**: Hafs from 'Asim (حفص عن عاصم) in standardized Uthmani Script (*Rasm al-Uthmani*).
- **Digital Provenance**: Verified digital text via Tanzil Project ([https://tanzil.net](https://tanzil.net)) and Al-Quran Cloud API ([https://alquran.cloud](https://alquran.cloud)).
