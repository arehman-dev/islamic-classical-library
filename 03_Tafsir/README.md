## Scholarly Provenance & Authority
- **Corpus Origin**: Open Academic Quran Tafsir API by spa5k ([https://github.com/spa5k/tafsir_api](https://github.com/spa5k/tafsir_api)).
- **Classical Transcriptions**: King Saud University Electronic Quran Project & Tanzil.
- **Granularity**: Structured ayah-by-ayah across all 114 Surahs in clean Markdown (`.md`) and Plain Text (`.txt`).
